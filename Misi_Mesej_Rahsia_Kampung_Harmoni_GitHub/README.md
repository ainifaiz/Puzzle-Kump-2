# 🧩 Misi Mesej Rahsia — Kampung Harmoni

Puzzle digital Pendidikan Moral Tahun 5 menggunakan gambar Karnival Sukaneka.

## Kandungan
- 12 keping puzzle digital (4 × 3)
- Interaksi klik-dua-keping untuk bertukar tempat
- Sokongan seret dan lepas pada komputer
- Semakan automatik apabila susunan gambar lengkap
- Fungsi **Balikkan Kepingan**
- 12 perkataan mesej rahsia:
  1. KERJASAMA
  2. DAPAT
  3. MENGUKUHKAN
  4. SEMANGAT
  5. PERPADUAN
  6. SERTA
  7. MEWUJUDKAN
  8. PERSEKITARAN
  9. YANG
  10. SIHAT
  11. DAN
  12. SELAMAT

## Cara guna di GitHub Pages
1. Muat naik semua fail dan folder dalam ZIP ini ke sebuah repository GitHub.
2. Pastikan `index.html` berada di peringkat utama repository.
3. Pergi ke **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih `main` dan folder `/ (root)`, kemudian **Save**.
5. Buka URL GitHub Pages yang diberikan oleh GitHub.

Tiada library luaran diperlukan. Aktiviti boleh dijalankan terus secara offline selepas semua fail dimuat turun.
